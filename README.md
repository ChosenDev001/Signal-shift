# Signal Shift

A small, mobile-friendly grid puzzle made with plain HTML, CSS, and JavaScript. It has eight levels, keyboard and touch controls, a move counter, collected-chip tracking, and a restart button.

## Run it

1. Download or clone this folder.
2. Open `index.html` in a browser. No install, server, API key, or internet connection is required.

## Upload to GitHub Pages

1. Create a GitHub repository (for example, `signal-shift`).
2. Upload **the contents of this folder** so `index.html` is in the repository's root, beside this README.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish the site. The Pages URL will appear in the same settings section.

## Controls

- Arrow keys or WASD: move
- R: restart the current level
- On phones: use the on-screen arrow buttons

## Project files

- `index.html` — the complete game; no external libraries or assets
- `README.md` — setup and GitHub Pages instructions
